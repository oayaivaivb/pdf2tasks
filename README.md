
# PDF Question Parser

CLI-утилита для распознавания (OCR) и парсинга сборников задач из PDF и Markdown-файлов с выгрузкой в форматы **Markdown** и **Excel (.xlsx)**.

Распознавание PDF выполняется локально с помощью **Tesseract OCR** и утилиты растеризации `pdftoppm`.

---

## Возможности

- Распознавание сканов и документов PDF через Tesseract OCR.
- Автоматическое разбиение документа на разделы («Часть 1», «Часть 2», «Часть 3») и отдельные задачи («B1», «C1» и т.д.).
- Исправление типовых ошибок OCR (буквы-двойники, артефакты в физических и математических обозначениях).
- Подключение пользовательских regex-правил исправлений через файл `fixes.txt`.
- Экспорт результатов в форматированный Excel (.xlsx) с автоподбором ширины колонок и в чистый Markdown.

---

## Требования и установка

### 1. Системные зависимости (Tesseract и Poppler)

Для работы с PDF требуются `tesseract-ocr` и `poppler-utils` (содержит `pdftoppm`).

**Ubuntu / Debian / WSL:**
```bash
sudo apt update
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-ell poppler-utils

```

*(Пакет `tesseract-ocr-ell` нужен для распознавания греческих символов: $\Delta$, $\varphi$, $\alpha$ и т.д.)*

### 2. Зависимости Python

Создайте виртуальное окружение и установите библиотеку для работы с Excel:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install openpyxl

```

## Использование

### 1. Распознавание PDF-файла

Базовый запуск парсинга PDF (результаты будут сохранены в папку `out/`):

```bash
python parse_questions.py input.pdf -o out

```

С указанием языковых пакетов Tesseract (русский + английский + греческий):

```bash
python parse_questions.py input.pdf -o out --tess-lang rus+eng+ell

```

### 2. Повторный разбор уже распознанного Markdown

Если PDF уже был распознан ранее, можно запустить повторную обработку промежуточного файла `raw.md`:

```bash
python parse_questions.py out/raw.md -o out --ocr

```

## Основные параметры CLI

| Параметр | Описание |
| --- | --- |
| `input` | Входной файл: скан `.pdf` или готовый текстовый `.md` |
| `-o`, `--out` | Каталог для сохранения результатов (по умолчанию `.`) |
| `--ocr` | Включает режим агрессивной OCR-очистки (склейка дефисных переносов, рамочные номера) |
| `--unwrap` | Схлопывает одиночные переносы строк внутри условий задач |
| `--fixes` | Путь к файлу кастомных замен (по умолчанию ищется `fixes.txt` рядом) |
| `--tess-lang` | Языки для Tesseract (по умолчанию `rus+eng`) |

---

## Пользовательские правила исправлений (`fixes.txt`)

Файл `fixes.txt` позволяет точечно чинить опечатки конкретного скана до этапа разбиения на задачи.

Синтаксис: `регулярное_выражение => замена` (строки с `#` игнорируются).

Пример:

```text
(?<![\w])и(?=\s*=\s*\d) => v
3,8 - 105 => 3,8 · 10⁵
(?<=[ТT] = )44(?=,) => 4 ч

```

## Структура вывода

После обработки в целевой директории формируются файлы:

* `raw.md` — сырой текст после Tesseract OCR;
* `raw_fixed.md` — текст после применения всех правил автозамен;
* `questions.md` — задачи, структурированные по частям и номерам;
* `questions.xlsx` — итоговая таблица со столбцами: *Часть*, *Номер вопроса*, *Вопрос*, *Рисунок*.
